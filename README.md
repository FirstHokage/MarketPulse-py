# MarketPulse-py 🚀

A lightweight, zero-dependency Python command-line utility to track real-time cryptocurrency, precious metal, and stock prices directly from the Windows terminal.

## Features
- **Zero Third-Party Dependencies:** Uses Python's built-in libraries (no `pip install` required).
- **Comprehensive Coverage:** Tracks major cryptos (BTC, ETH, SOL, XRP), precious metals (Gold, Silver, Platinum), and industrial metals (Copper).
- **Fast CLI Command:** Includes a Windows Batch wrapper for quick terminal queries.

## Requirements
- [Python 3.x](https://www.python.org/downloads/)
